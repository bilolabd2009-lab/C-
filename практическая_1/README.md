# Практическая 1. Рефакторинг legacy-кода: управление поливом теплицы

Исходный код лежит в [`legacy/greenhouse_legacy.cpp`](legacy/greenhouse_legacy.cpp) и не меняется.
Рефакторинг идёт в [`src/greenhouse.cpp`](src/greenhouse.cpp). Каждый этап сделан отдельным коммитом,
и после каждого все тесты проходят.

| Этап | Что сделано |
|---|---|
| 1. Фиксация поведения | golden-master тесты, эталон записан по legacy-версии |

## Как запустить тесты

Нужны `g++` (C++17) и Python 3.

```
python tests/run_tests.py            # проверить src/greenhouse.cpp
python tests/run_tests.py --legacy   # проверить исходник (должен проходить всегда)
python tests/run_tests.py --record   # перезаписать эталон по legacy (только если меняется сам набор сценариев)
```

## Этап 1. Фиксация поведения

Перед любыми правками поведение программы закреплено характеризационными тестами (golden master).
[`tests/run_tests.py`](tests/run_tests.py) собирает программу, подаёт на вход 27 сценариев и сравнивает
весь вывод **побайтово** вместе с **кодом возврата**. Эталон в `tests/cases/` (`*.in`, `*.out`, `*.code`)
снят с legacy-версии, поэтому тест проверяет «как было», а не «как должно быть».

Зафиксированное поведение, включая неочевидные моменты, которые рефакторинг обязан сохранить:

| Ситуация | Поведение |
|---|---|
| Влажность не число или ввод пуст | `Input error`, код 1 |
| Влажность вне `0..100` | `Invalid moisture`, код 2 (границы 0 и 100 допустимы) |
| Действие не число или конец ввода до `0` | `Input error`, код 1, итог **не** печатается |
| `0` | выход из цикла, печать итога, код 0 |
| `1` статус | считается операцией |
| `2` открыть | отказ, если клапан уже открыт или влажность ≥ 60; отказ операцией не считается |
| `3` закрыть | считается **всегда**, даже если клапан уже закрыт |
| `4` импульс | отказ, если клапан открыт или влажность ≥ 85; иначе +20 % (не выше 100) и +5 л |
| неизвестный код | `Unknown action`, операцией не считается |
| 8 операций | цикл завершается сам, следующий ввод не читается |
| приглашения `Moisture: ` и `Action 0/1/2/3/4: ` | печатаются без перевода строки |
