## 2 Почему при работе с int* важно проверять nullptr? Укажите опасную строку payWithPointer, порядок проверок и проблему некорректной цены.

Опасная строка: if (*balance >= price) — здесь *balance разыменовывает указатель. Если balance == nullptr, программа упадёт. Поэтому сначала if (balance == nullptr) return false;, потом уже лезем в *balance.

Отрицательная цена: *balance -= price при price = -50 прибавит 50 вместо списания. Нужна проверка if (price <= 0) return false;.

Порядок проверок: nullptr → цена > 0 → баланс ≥ 0 → хватает денег → списание.
